# Beneros-ClassWall

1. What is the difference between a cookie and a session?

A cookie stores information in the user's browser, while a session stores information on the server. Both can help a website remember information about a user.

2. Where is each one stored (browser or server)?

Cookies are stored in the browser, while session data is stored on the server. The browser normally holds a session ID that identifies the user's session.

3. Why do we use prepared statements?

We use prepared statements to protect our database from SQL injection. They separate SQL commands from user-provided data, making database queries safer.
